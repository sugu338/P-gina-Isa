# Para mi aceitunita 💗

PWA romántica para Agustín e Isabella: rompecabezas deslizante 4×4, vista previa, movimientos, cronómetro, carta final y descarga de un corazón SVG animado.

## Foto de ustedes
La foto adjunta no quedó disponible en el entorno de creación de archivos de esta ejecución. Para completar el proyecto, guardá la foto de ustedes en `assets/` con el nombre `foto-pareja.jpg`. Si tu imagen es PNG, editá la variable `photo` al comienzo de `app.js` para usar `./assets/foto-pareja.png`.

## Probar localmente
Desde esta carpeta ejecutá `python -m http.server 8080` y abrí `http://localhost:8080`. Para instalar una PWA se requiere localhost o HTTPS; no basta abrir el archivo HTML directamente.

## Publicar gratis en GitHub Pages
1. Subí todos los archivos al repositorio de GitHub.
2. Abrí Settings → Pages.
3. Elegí Deploy from a branch, branch `main`, carpeta `/ (root)` y guardá.
4. Compartí el enlace HTTPS con Isabella.
5. En Android/Chrome: menú ⋮ → “Instalar aplicación” o “Agregar a pantalla de inicio”.

## Importante sobre Android
Una PWA puede instalarse como app web, pero no crear un widget nativo independiente en la pantalla de inicio. El corazón animado se muestra dentro de la experiencia web y también se puede guardar como SVG animado.
